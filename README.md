## 📖 Project Overview

GBStation is a desktop-based stationery management system developed using VB.NET and Visual Studio 2022.

The system helps manage stationery products, customer information, sales transactions, and business reports through a simple and user-friendly interface.

## ✨ Key Features

* 🔐 **Login System** — Provides basic user authentication.
* 🏠 **Dashboard** — Allows easy navigation between system modules.
* 📦 **Product Management** — Add, update, delete, search, and view products.
* 👥 **Customer Management** — Manage customer records.
* 🛒 **Sales and Transactions** — Calculate totals, discounts, and taxes, and save sales.
* 📊 **Reports** — Generate and export business reports.
* ⚙️ **Settings** — Customize fonts and background colors.
* 📋 **Clipboard Operations** — Copy and paste product names.
* 💾 **Database Integration** — Store and retrieve records using SQL Server.

## 🚀 How to Run the Project

1. Install Visual Studio 2022 with the required .NET desktop development tools.
2. Download or clone this repository.
3. Open `GBStation.slnx` in Visual Studio.
4. Install and configure SQL Server LocalDB.
5. Create the `GBStationDB` database with the required tables.
6. Ensure the application's database connection strings match your SQL Server instance.
7. Build and run the project.

**Note:** The application was developed using the `(localdb)\ProjectModels` SQL Server instance. Database functionality requires the database to be configured correctly.
